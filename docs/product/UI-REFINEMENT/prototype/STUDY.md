# Formative study kit

Status: prepared, genuine participant evidence PENDING. The study is an interactive example; it cannot score, bid, settle money or verify production authority. Agent engineering checks are reported separately. Product review of concrete artifacts remains pending.

Recruit six to eight people representing organiser, scorer, owner, spectator and manager/finance/operator responsibilities. Do not pool a failed role with a successful one. Counterbalance baseline/prototype order within a role; record participant familiarity, device/browser, theme, task order and assistance. No invented observations or extrapolated conversion claim.

| Task | Prompt (no control name hint) | Correct understanding / critical failure |
| --- | --- | --- |
| Home | Your cricket match is live and you also own an auction team. Continue the match, then find the room. | Names responsibility/scope; no silent role/permission switch |
| Cricket | Record four, explore loss of connectivity, then return Home and resume. | Distinguishes accepted/pending; no belief offline entry is server accepted |
| Timed | Record a goal for Falcons, review attribution, then explore clock/event controls. | Identifies side/player/time before record; no unintended opposing goal |
| Round | Enter both squads' results including zero kills, collapse/reopen, review then cancel. | All squads/players included; retained input; no zero omitted |
| Public | Find the scorecard, explain update eligibility, then inspect unavailable details. | Never assumes missing/delayed/private details are zero or current |
| Auction | Inspect the next bid and purse consequence; cancel and return to live room. | Correct amount/team/purse; no belief prototype submits money |

Before task, ask the participant what they expect next. After task, ask what changed, whether it is accepted and how to return/recover. Record completion without assistance, time, wrong actions, comprehension, observed difficulty, quotes with consent, severity and follow-up. Stop/redesign any critical consequence/authority/privacy/recovery misunderstanding. Engineering build pass does not establish participant study pass.

Report columns: anonymised participant, role/scope, familiarity, device, order, task, success unaided, seconds, wrong actions, accepted/pending comprehension, return success, issue severity, observation, disposition and retest. Leave rows empty until sessions occur. Physical device/manual assistive technology and field measurements remain in ACCEPTANCE.md.
