# Six-design action and return map

Engineering prototype reference; no real APIs and no canonical sport simulation. Existing controls not demonstrated here remain required in production packages, not deleted. Examples use current Daylight/Floodlight CSS and a baseline self-hosted Geist font; no new runtime framework/dependency.

| Design | Existing authority / action basis | Proposed placement | States / return | Production verification |
| --- | --- | --- | --- | --- |
| Home | homeSections/chooseNextStep; authorised readers in TASK-MAP | Named live task first, every concurrent obligation visible, role/season context on each | Explicit task link, Home return; no invisible role mode. Unavailable tasks require truthful state | E05 sole/combined roles, every scope, stable selection; example readiness is not live |
| Delivery | pad.tsx and legal engine-generated actions | Retain run-key group; extras/wicket in labelled disclosure; correction and finish separate from routine entry | Accepted score unchanged on pending/rejected; lost claim disables; cancel correction/finalisation; Home preserves supported queue | E04 every legal dismissal/extra, batter/bowler, setup, claim/recovery, accepted correction/finalisation/public result. Prototype sheets demonstrate disclosure, not rules |
| Timed | families/timed-pad.tsx active players/clock/attribution | Score/clock at top; team before player; event workspace with recent history beside it on laptop | Correct team choice, explicit pause, reviewed goal, secondary event disclosure, cancel return with values | E08 football/basketball/hockey variants, periods/points/cards/substitution/shootout/restart/interruption; example choices don't broaden legal actions |
| Placement | families/placement-pad.tsx all teamIds and playerKills | Collapsible squads with compact labelled player rows; completeness/review panel | Every entry including zero, invalid placement/negative kills retains fields; cancel leaves form | E08 all squads/players, tied/limited/unsupported/excluded/void/restart state, whole-round correction and manager confirmations |
| Public match | publicPage / LiveView and existing scorecard sidecars | Situation first; explicit Live/Scorecard choices; eligibility/timestamp beside result | Missing/private/delayed never fabricated; safe public parent/share | E04/E13 current trust/delay/minors SSR/poll/socket/chart/broadcast and terminal result |
| Owner auction | existing live-room bid/engine acknowledgement | Player → accepted bid → next bid → consequence; purse/slots with squad link | Confirm/cancel, pending/rejected never accepted; claim/permission lost disables. No optimistic amount | E09 exact amount/rules/purse/slots/late changes, conductor isolation/reconnect/rollback |

Prototype-only navigation bar and scenario selector are study instrumentation, not proposed production shell. Production remains current desktop rail/at-most-five phone model and task-specific scoring chrome. Participant/device/manual AT acceptance remains pending. Automated axe/keyboard/reflow evidence is scoped engineering evidence only.
