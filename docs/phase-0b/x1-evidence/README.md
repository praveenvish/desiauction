# X1 Evidence Intake

Drop real session artifacts here. The Analysis Board reconvenes only on this folder's contents (see `../X1_SYNTHESIS_00_NO_EVIDENCE.md`).

## Per participant
1. Copy `OBSERVATION_SHEET_TEMPLATE.md` → `P1.md`, `P2.md`, … (`P-F.md` for the founder pilot). Fill it **during** the session — verbatims in the language spoken.
2. Recordings: keep video/audio files out of git (too large). Store them in one folder on this machine or a drive, and paste the path/link into the sheet's `Recording file(s)` line.
3. After the 48-hour call, fill the sheet's final section. A sheet without the 48h section is an incomplete packet item (log "unreachable ×2" if so).

## Packet completeness (from protocol §13/§14)
- Minimum: 6 neutral participants, ≥2 organizers, plus P-F.
- Every sheet: five-second verbatims, task rows T1–T7, trust-test time, comparison answers, interview verbatims, 48h section.
- Deviations from the protocol are LOGGED on the sheet, never smoothed over. A logged deviation is data; a hidden one is contamination.

## When complete
Commit the sheets, then reconvene the Analysis Board with: "X1 packet complete — synthesize." The Board will fill the Evidence Ledger (`../EVIDENCE_PLAN.md` §11), evaluate decision rules D-1…D-12, and issue verdicts for H1, H2, H5, H6, H7, H8, H9.
