# @desiauction/db

The shared data layer (IP-2_DESIGN D1): Drizzle schema, SQL migrations, client factory. Consumed by `apps/web` and `apps/engine`; imports only `drizzle-orm`, `postgres`, `ulidx` (dep-cruiser enforced). Tenant tables carry `org_id` with RLS policies FORCEd in migrations (C-13). At runtime, tenant isolation is enforced by application-layer query scoping; `withTenant` (which would set the per-request Postgres context) is **not yet wired into the serving path**, and the app connects as an RLS-exempt role — so the RLS policies are latent defense-in-depth, proven under a non-superuser role in tests and engaged in production only once queries route through `withTenant` under a non-BYPASSRLS role (named pre-deploy item: IP-3 closure report §6). Migrations: `pnpm db:generate` → review SQL → `pnpm db:migrate`; forward-only in production (IP-0_DESIGN §20).
